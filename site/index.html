How it works

Reference

Drop in a track. Alma measures its tempo, key and structure, bar by bar.

Sounds

Point it at your sample pack. It picks a kit — kick, bass, hats, percussion, synths — and you can swap any of them.

Direction

Choose a style and a length. Listen to the result before anything is written.

Build

Alma writes the clips, markers and sidechain into the empty Live Set in front. Edit everything.
